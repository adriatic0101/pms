# Processed data

`ca_county_pms_analysis.csv` is created here only when all 58 counties have a validated, non-synthetic PMS outcome and the raw covariate files pass validation.

No placeholder analytic dataset is included.

`ca_county_socioeconomic_acs_2024.csv` is a public, 58-county covariate file
created from official 2024 ACS 5-year detailed-table estimates. Its provenance
and calculations are documented in `documentation/acs_socioeconomic_data.md`.
